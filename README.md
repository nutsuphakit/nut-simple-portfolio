# Nut Suphakit - Portfolio

Modern, minimalist portfolio website for a Data Analyst.

## 🚀 Features
- **Project Showcase:** Highlights key data analysis projects.
- **Responsive Design:** Optimized for all screen sizes.
- **Dark Mode Support:** Toggle between light and dark themes.
- **Custom Styling:** Clean layout with JetBrains Mono typography.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure.
- **Vanilla CSS:** Custom properties and flexbox layout.
- **Vanilla JavaScript:** Theme toggling and interactive elements.

## 📂 Project Structure
- `docs/`: Contains the complete website (index.html, CSS, JS) for GitHub Pages deployment.
- `portfolio-setup.md`: Original project planning document.

## 🌐 Deployment
Hosted on **GitHub Pages**. The site is deployed from the `/docs` directory.
